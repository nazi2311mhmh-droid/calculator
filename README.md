ابتدا مطمئن شوید Python روی سیستم شما نصب است.

🎮 نحوه استفاده
بعد از اجرای برنامه، یک منو مانند زیر نمایش داده می‌شود:

1=jam adad
2=zarb adad
3=taghsim adad
4=menha adad
5=bakhshpaziri
6=khoroj

با وارد کردن شماره گزینه، عملیات موردنظر انتخاب می‌شود.

مثال
برای جمع دو عدد:

**gozine ra vared konid** : 1
adad aval = 10
adad dovom = 5
15.0

برای بررسی بخش‌پذیری:

**gozine ra vared konid** : 5
adad aval = 10
adad dovom = 2
adad 10 bar 2 bakhshpazir ast.

🧩 توابع برنامه
برنامه از چند تابع ساده برای انجام عملیات استفاده می‌کند:

def add(a, b):
    return a + b

def menha(a, b):
    return a - b

def zarb(a, b):
    return a * b

def taghsim(a, b):
    return a / b

همچنین تابع bakhpaziri بررسی می‌کند که آیا عدد اول بر عدد دوم بخش‌پذیر است یا خیر.
